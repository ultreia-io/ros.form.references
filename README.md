Share IOTC Regional Observer Scheme code lists, registries and reference snapshots between exporters and validators.

Select references by gear and model version, using `ros.form.model` and `form.references`.

## Installation

Install the latest released version:

```r
install.packages("pak") # Once
pak::pak("ultreia-io/ros.form.references@*release")
```

`pak` installs the required dependencies automatically.

For the development version:

```r
pak::pak("ultreia-io/ros.form.references@develop")
```
